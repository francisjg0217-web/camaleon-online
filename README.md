# Camaleón Online
Juego web multijugador. Sin dependencias: solo necesita Node 18 o superior.

Probar en tu computadora: `node server.js` y abre http://localhost:3000

## Publicarlo (gratis para empezar)
1. Sube esta carpeta a un repositorio de GitHub.
2. En render.com crea un "Web Service" desde ese repositorio. Build command: (vacío). Start command: `node server.js`.
3. Render te da un link público (algo.onrender.com). Cualquiera puede entrar sin cuenta.
4. Para tener un dominio propio, compra uno y conéctalo en Settings > Custom Domains.
5. Para aparecer en Google: registra tu dominio en Google Search Console y envía la página principal.
